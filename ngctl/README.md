# Nebula Graph ngctl

This directory contains ngctl, a tool to connect the metad service of a supercluster to mange a superclsuter or clusters, or hosts to install and run NebulaGraph services.

## Prerequisites

* Deploy a nebula agent on each host involved. Its IP address and port number are needed to config and run ngctl's commands.
* Prepare and deploy certificates and keys for SSL transfers.
* To install NebulaGraph, NebulaGraph packages are needed.

## Examples

### Example Procedure

Create a supercluster
```ngctl supercluster create --config ./config.yaml```

Login to the supercluster just created (whose port is configured to be 49559)
```ngctl supercluster login -P 49559 -u root```

Create a cluster.
```ngctl cluster create -c testcluster```

Install NebulaGraph packages on hosts configured in the config file.
```ngctl host install -f ./config.yaml -c testcluster```

Add hosts into the cluster.
```ngctl host add -f ./config.yaml -c testcluster```

Add services into the cluster.
```
ngctl service add -t storaged -H 127.0.0.1 -P 49779 -c testcluster
ngctl service add -t graphd -H 127.0.0.1 -P 49669 -c testcluster
```

Start services in the cluster.
```
ngctl service start -t storaged -H 127.0.0.1 -P 49779 -f ./config.yaml
ngctl service start -t graphd -H 127.0.0.1 -P 49669 -f ./config.yaml
```

Show all services in the cluster.
```
ngctl service show -c testcluster
```

Stop a storaged service.
```
ngctl service stop -t storaged -H 127.0.0.1 -P 49779 -f ./config.yaml
```

Stop a graphd service.
```
ngctl service stop -t graphd -H 127.0.0.1 -P 49669 -f ./config.yaml
```

Drop a storaged service.
```
ngctl service drop -t storaged -H 127.0.0.1 -P 49779 -c testcluster
```

Drop a graphd service.
```
ngctl service drop -t graphd -H 127.0.0.1 -P 49669 -c testcluster
```

Drop hosts in a cluster.
```
ngctl host drop -f ./config.yaml -c testcluster
```

Uninstall packages on a NebulaGraph cluster.
```
ngctl host uninstall -f ./config.yaml -c testcluster
```

Show hosts in a cluster.
```
ngctl host show -c testcluster
```

Stop a supercluster.
```
ngctl supercluster stop --config ./config.yaml
```

Logout the supercluster
```
ngctl supercluster logout
```
