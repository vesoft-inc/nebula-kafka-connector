Official Nebula Go client which communicates with Nebula service using [fbthrift](https://github.com/facebook/fbthrift/). 

The code in **master branch** will be updated to accommodate the nightly changes made in Nebula Graph.
To Use the console with a stable release of Nebula Graph, please check the branches and use the corresponding version.

## Install & Update(TODO)
This is private repo so to get this module, you need to run
`go env -w GOPRIVATE="github.com/vesoft-inc/*"`

To install: `go get -u -v github.com/vesoft-inc/nebula-ng-tools/golang`

For more details check https://pkg.go.dev/cmd/go#hdr-Configuration_for_downloading_non_public_code
